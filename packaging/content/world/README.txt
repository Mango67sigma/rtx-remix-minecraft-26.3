RTX Remix Showcase World @VERSION@
================================

NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG
OR MICROSOFT.

The showcase world for RTX Remix for Minecraft, a Fabric mod that path traces
Minecraft Java Edition through NVIDIA RTX Remix. BlockWorks built it for the
project, and the renderer was tuned against it, so the places it visits are
where the mod looks and runs best.

This copy comes with an unofficial community port of the mod to Minecraft Java
Edition 26.3, which is not affiliated with, endorsed by, or supported by
NVIDIA.

RTX Remix for Minecraft: https://github.com/NVIDIAGameWorks/rtx-remix-minecraft
The port to Minecraft 26.3: https://github.com/Mango67sigma/rtx-remix-minecraft-26.3


Requirements
------------

- Minecraft Java Edition 26.3. The world was saved in 1.21.1, and Minecraft
  upgrades it the first time you open it.
- The port of RTX Remix for Minecraft to 26.3. The world was built to be seen
  path traced, and its Copper Beacons are a block the mod adds.
- Optional: RTX Remix Materials, the texture resource pack made for the mod.


Install
-------

1. Extract the download into the saves folder of your Minecraft game
   directory, so that saves contains the "NVIDIA RTX Demo" folder.
2. In Minecraft, open Singleplayer and choose NVIDIA RTX Demo. You start in
   Creative mode with commands allowed. The first time, Minecraft asks
   whether to create a backup before it upgrades the world, then whether to
   join it now.
