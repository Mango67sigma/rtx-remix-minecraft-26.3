RTX Remix Materials @VERSION@
==========================

NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG
OR MICROSOFT.

A 64x texture resource pack created by an art team at NVIDIA for RTX Remix for
Minecraft, a Fabric mod that path traces the game through NVIDIA RTX Remix.
Its normal and specular maps follow the LabPBR standard
(https://shaderlabs.org/wiki/LabPBR_Material_Standard), so other renderers and
shader packs that read LabPBR may be able to use it too, but it has only been
tested with RTX Remix for Minecraft. Its _sss subsurface maps are that mod's
own addition.

This copy comes with an unofficial community port of the mod to Minecraft Java
Edition 26.3, which is not affiliated with, endorsed by, or supported by
NVIDIA. The pack was made for Minecraft Java Edition 1.21.1; this copy's
pack.mcmeta declares the resource pack format of 26.3.

RTX Remix for Minecraft: https://github.com/NVIDIAGameWorks/rtx-remix-minecraft
The port to Minecraft 26.3: https://github.com/Mango67sigma/rtx-remix-minecraft-26.3


Install
-------

1. Put this zip, without extracting it, in the resourcepacks folder of your
   Minecraft game directory.
2. In Minecraft, open Options > Resource Packs and move the pack to the
   Selected list.
